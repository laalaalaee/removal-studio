# Removal Studio ✨

A fast, client-side background removal tool built with React and Vite.

## 🚀 Features
* **100% Client-Side:** Processes images directly in the browser for maximum privacy and speed.
* **Modern Stack:** React, Vite, Tailwind CSS.
* **High Performance:** Optimized for fast rendering and minimal overhead.

## 💻 Getting Started
1. Clone the repository
2. Install dependencies with npm install
3. Run the development server with npm run dev
